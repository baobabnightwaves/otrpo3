### 4. ✅ REST API для Cities (основная сущность)

**Реализованные endpoints:**
- `GET /api/cities` - Получить все города
- `GET /api/cities/{id}` - Получить конкретный город
- `POST /api/cities` - Создать новый город
- `PUT /api/cities/{id}` - Обновить город
- `DELETE /api/cities/{id}` - Удалить город

**Создан Resource:**
- `CityResource.php` с полем `friendsWithAuthor`

**Защита:**
- Все routes защищены middleware `auth:api`
- Требуется Bearer токен

**Статус:** ✅ ЗАВЕРШЕНО

---

### 5. ✅ REST API для Comments (вспомогательная сущность)

**Реализованные endpoints:**
- `GET /api/comments` - Получить все комментарии
- `GET /api/comments/{id}` - Получить конкретный комментарий
- `POST /api/comments` - Создать новый комментарий
- `PUT /api/comments/{id}` - Обновить комментарий (только автор)
- `DELETE /api/comments/{id}` - Удалить комментарий (только автор)

**Создан Resource:**
- `CommentResource.php` 
  - Включает данные связанного City
  - Включает данные User (автора)
  - Поле `friendsWithAuthor`

**Авторизация:**
- Пользователь может изменять только свои комментарии

**Статус:** ✅ ЗАВЕРШЕНО

## 🧪 Тестирование

### Шаги для проверки:

1. **Запустить сервер**
   ```bash
   php artisan serve
   ```
   Сервер: `http://localhost:8000`

2. **Создать пользователя**
   - Открыть: `http://localhost:8000/register`
   - Зарегистрироваться

3. **Получить токен**
   - Кликнуть на имя пользователя в header
   - Выбрать "Dashboard (API Токены)"
   - Нажать "Создать новый токен"
   - Скопировать токен

4. **Тестировать API с Postman**
   - Добавить header: `Authorization: Bearer YOUR_TOKEN`
   - Тестировать endpoints:
     - GET `/api/cities`
     - POST `/api/cities`
     - GET `/api/comments`
     - POST `/api/comments`
     - И т.д.

### Документация:
См. файл `tmp_rovodev_API_TESTING_GUIDE.md` для:
- Детальных примеров запросов
- Настройки Postman
- Примеров curl команд
